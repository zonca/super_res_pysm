Here we store the config files and parameters used for the `256_set3_b` simulation. We used the [SR3 model](https://github.com/javierhndev/Super-Resolution-SR3/tree/v1.0)  (tag v1.0)

Before running the model, I created the data and ran the *prepare* scripts.

In this folder there is a set of yaml/json file I used to complete this simulation:
- `job_create_dataset.yaml`: This yaml file deploys a pod on Voyager to execute `dataset_generation.py`. That script creates the training and testing datasets from images generated by PySM. The dataset is made of `png` files.
- `job_prepare_data.yaml`: This pod executes a script from the original SR3 model that generates the low resolution images (using pytorch/pillow) from the training dataset and combines them into an `lmdb` file.
- `job_prepare_data_test.yaml`: Same as above but for the *testing* dataset.
- `sr_sr3_64_256_set3_b.json`: Config file used in the SR3 model for this run.
- `job_train_8cards_pod_set3`: yaml file that launches a pod on Voyager with 8 Gaudi cards and executes the SR3 model.
